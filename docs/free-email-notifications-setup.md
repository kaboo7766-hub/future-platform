# إعداد تنبيهات البريد المجانية

هذا النظام يستخدم GitHub Actions المجاني للمستودعات العامة، وGmail SMTP لإرسال الرسائل، وFirebase Admin SDK لقراءة أحداث Firestore. لا يحتاج إلى Firebase Blaze أو Firebase Storage.

## ما الذي يرسل تنبيهًا؟
- كل مستند جديد في مجموعة `notifications` (بما في ذلك الإعلانات والواجبات والإشعارات الموجهة).
- طلب تسجيل معلم جديد بحالة `pending`.
- إنشاء شهادة جديدة.
- اعتماد شهادة أو رفضها.
- اعتماد المعلم أو تعديل صلاحية مستخدم عند تسجيل العملية في `activityLogs`.
- تصحيح واجب عند وجود `gradedAt` في `submissions`.

يعمل الفحص المجدول كل خمس دقائق تقريبًا؛ قد يتأخر التنفيذ قليلًا بسبب جدولة GitHub Actions. لا يعيد إرسال الحدث نفسه بعد تسجيل نجاح إرساله.

## الإعداد المطلوب مرة واحدة

### 1) إعداد Gmail
استخدم حساب الإرسال `kaboo7766@gmail.com`:
1. فعّل التحقق بخطوتين لحساب Google.
2. افتح إعدادات حساب Google وابحث عن **App passwords / كلمات مرور التطبيقات**.
3. أنشئ كلمة مرور تطبيق باسم `GitHub Actions`، وانسخ كلمة المرور المكونة من 16 حرفًا. لا تستخدم كلمة مرور Gmail العادية.

### 2) إنشاء مفتاح خدمة Firebase
1. افتح Firebase Console ثم إعدادات المشروع.
2. افتح تبويب **Service accounts / حسابات الخدمة**.
3. أنشئ مفتاحًا خاصًا جديدًا بصيغة JSON لمشروع Firebase الصحيح.
4. احتفظ بالملف على جهازك ولا ترفعه إلى المستودع ولا ترسله في المحادثة.

### 3) إضافة أسرار GitHub
افتح المستودع ثم **Settings → Secrets and variables → Actions → New repository secret**، وأضف الأسرار التالية:

- `GMAIL_USER`: `kaboo7766@gmail.com`
- `GMAIL_APP_PASSWORD`: كلمة مرور التطبيق التي أنشأتها (يمكن إدخالها بدون مسافات).
- `FIREBASE_SERVICE_ACCOUNT`: محتوى ملف JSON كاملًا، من أول قوس `{` إلى آخر قوس `}`.

مفتاح خدمة Firebase يمنح صلاحيات إدارية على قاعدة البيانات؛ خزّنه في GitHub Secrets فقط، ولا تضعه في ملفات المشروع أو Vercel أو الواجهة.

### 4) تفعيل التشغيل
بعد دمج هذا التغيير في الفرع الافتراضي `main`:
1. افتح تبويب **Actions** في GitHub.
2. اختر **Free platform email notifications**.
3. اضغط **Run workflow** لتجربة أول تشغيل يدوي.
4. افتح سجل التشغيل وتأكد من ظهور رسالة نجاح. بعد ذلك يعمل الجدول تلقائيًا كل خمس دقائق تقريبًا.

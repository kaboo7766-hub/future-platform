# إعداد خادم التصحيح الآمن على Vercel

تحتاج واجهات التصحيح والترحيل إلى مفتاح حساب خدمة Firebase. لا تضع هذا المفتاح في ملفات الموقع أو GitHub، ولا ترسله في المحادثة.

## 1. إنشاء مفتاح خدمة Firebase
1. افتح Firebase Console واختر نفس مشروع Firebase المستخدم في منصة المستقبل.
2. افتح إعدادات المشروع ثم تبويب **Service accounts**.
3. اختر **Generate new private key** ونزّل ملف JSON.
4. احتفظ بالملف في مكان آمن. لا ترفعه إلى GitHub ولا تشاركه مع أي شخص.

## 2. إضافة السر إلى Vercel Preview فقط
1. افتح مشروع `future-platform` في Vercel.
2. افتح **Settings → Environment Variables**.
3. أضف متغيرًا اسمه `FIREBASE_SERVICE_ACCOUNT_JSON`.
4. ضع محتوى ملف JSON كاملًا كقيمة للمتغير.
5. اختر **Preview فقط** في البداية، ولا تفعّله على Production قبل الاختبار.
6. تأكد أن متغيرات `VITE_FIREBASE_PROJECT_ID` الموجودة في Preview تشير إلى مشروع Firebase نفسه.

يجب أن يمتلك حساب الخدمة صلاحية الوصول إلى Firestore في المشروع. لا نحتاج إلى Firebase Storage.

## 3. اختبار نسخة Preview
بعد إضافة المتغير، أعد نشر فرع `improve/performance-and-auth` ثم اختبر:
- تسجيل الدخول بحساب طالب.
- حل اختبار جديد منشور.
- محاولة إرسال إجابات غير مكتملة أو إعادة اختبار لا يسمح بالإعادة.
- التأكد من ظهور النتيجة للطالب وولي الأمر.
- تسجيل الدخول بحساب مدير والضغط على زر «تأمين الاختبارات القديمة» في لوحة المدير.

## تنبيه حول الاختبارات القديمة
الاختبارات التي أُنشئت قبل هذا التحديث قد تحتوي الإجابات الصحيحة داخل مستند الاختبار القديم. يجب تشغيل عملية الترحيل بحساب المدير بعد إعداد سر Vercel؛ ستنقل الإجابات إلى `quizAnswerKeys` وتزيلها من المستند الذي يقرأه الطالب.

لا تنقل متغير الخدمة إلى Production قبل نجاح اختبارات Preview ومراجعة الصلاحيات.

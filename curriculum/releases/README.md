# Curriculum releases

ضع كل إصدار في ملف JSON مستقل داخل هذا المجلد، وسمّه وفق الدولة والنظام والصف والمادة والسنة، مثال:

`EG/general_education/2026-2027/g4/science.json`

يجب أن يحتوي الإصدار على:
- الدولة والنظام والصف والمادة والسنة والفصل الدراسي.
- مصدر رسمي محدد ورابط الطبعة وتاريخ التحقق منها.
- الوحدات مرتبة، ولكل وحدة دروس مرتبة.
- أهداف وشرح وأنشطة وتدريبات لكل درس.
- امتحان للوحدة وامتحان شامل للمادة.
- حالة المراجعة: `draft` ثم `in_review` ثم `approved` ثم `published`.

لا يُسمح بنشر أي إصدار لمجرد استيراده. يجب أن يتضمن الإصدار المعتمد بيانات المراجع وتاريخ المراجعة. لا تنسخ صفحات الكتب أو بنوك الأسئلة المحمية حرفيًا؛ أنشئ شرحًا وأسئلة أصلية تغطي نواتج التعلم.

## حدود التحديث الآلي

المراقب اليومي يفحص إتاحة بوابات المصادر الرسمية ويسجل بصمة الاستجابة، ثم يتحقق من بنية ملفات المناهج الموجودة. اختلاف البصمة إشارة تستدعي مراجعة الطبعة الجديدة، وليس دليلًا كافيًا على تغير المنهج. لا يستورد المراقب نصوص الكتب ولا ينشرها تلقائيًا. تظل مطابقة الوحدات والدروس والامتحانات للكتاب الرسمي وموافقة المسؤول شرطًا قبل إظهارها للطلاب.
